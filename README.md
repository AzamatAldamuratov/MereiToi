# Мерей Той

Страница-приглашение по макету Figma, node `13:34` (1000 × 4883). Сервер использует встроенные модули Node.js; дополнительные пакеты не нужны.

## Запуск в Windows

Откройте PowerShell в папке проекта и запустите сервер:

```powershell
node server.js
```

Затем откройте <http://localhost:4173/>. Страницу можно открыть напрямую через `index.html` для просмотра, но отправка RSVP будет доступна только через `server.js`.

## Дата торжества

Дата для обратного отсчёта хранится в `script.js`: 11 декабря 2026 года, 16:00, часовой пояс `Asia/Qyzylorda`. Часовой пояс преобразуется через IANA `Intl` API, без жёстко заданного смещения UTC.

## RSVP и Telegram-бот

Форма отправляет имя и выбранный вариант ответа на маршрут `/api/rsvp`. Сервер пересылает заявку в Telegram и никогда не отдаёт токен браузеру.

1. Создайте локальный файл конфигурации: `Copy-Item .env.example .env`.
2. Запишите в `.env` `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
3. Запустите сервер командой `node server.js`.

`TELEGRAM_CHAT_ID` — ID личного чата или группы, куда бот будет присылать RSVP. Добавьте бота в нужную группу и выдайте ему право отправлять сообщения. Файл `.env` исключён из Git. Если переменные не заданы, сервер не сообщает об успешной отправке и возвращает временную ошибку.

**Безопасность токена:** токен, отправленный в сообщении, следует отозвать в BotFather и выпустить новый. Новый токен вносите только в локальный `.env` и не публикуйте в браузерном коде или репозитории.
